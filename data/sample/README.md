# Sample model — a fictional university's curriculum slice

Forty-odd elements and ninety relationships that exercise every edge of the
metamodel's Information diagram plus the neighbours it needs (applications,
technology, integrations, positions, organisation units, capabilities, a work
package). Names are invented; nothing here is real data.

Files follow the CSV contract in `connectors/README.md`. Load with
`make seed` (or `uv run ea import data/sample --source sample`).
